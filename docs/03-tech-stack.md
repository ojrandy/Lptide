# 03 — Tech Stack

Selection rule: **fast to build, secure by default, no external services, one deployable.**

| Concern | Choice | Why |
|---|---|---|
| Framework | **Next.js 16.4** (App Router, Turbopack), **React 19.3**, TypeScript strict | Storefront and admin in one app. RSC keeps the storefront fast and SEO-friendly. |
| Styling | **Tailwind CSS 4.3** with tokens in `globals.css` | Fastest way to reproduce an existing look |
| Admin UI | **shadcn/ui** (copied components) + **lucide-react** icons | Tables and forms ready in minutes, no runtime dependency |
| DB | **SQLite** via Node's built-in **`node:sqlite`** (`DatabaseSync`) | Zero ops, no native addon. better-sqlite3 was rejected because Windows Application Control blocks its compiled `.node` on the dev machine. |
| ORM | **Drizzle ORM** (`drizzle-orm/sqlite-proxy` over `node:sqlite`) + drizzle-kit (generate only) | Typed SQL, tiny runtime. Migrations are generated by drizzle-kit and applied by `scripts/migrate.ts` using `drizzle-orm/sqlite-proxy/migrator`. |
| Validation | **Zod** | One schema for forms, Server Actions and the seed |
| Mutations | **Server Actions** | No REST layer, CSRF protection built in |
| Admin auth | **jose** (JWT cookie) + **bcryptjs** | Two small libraries. Auth.js is overkill for 1–3 admins. |
| Cart | **Zustand** (persist → localStorage) | Client-only cart with no server sessions. Prices are re-validated server-side. |
| Email | **Nodemailer** → client's own SMTP mailbox | No third-party email API, mail sent from their domain |
| Markdown | **react-markdown** | Category intros and payment instructions |
| Images | `next/image` (sharp) + local `UPLOAD_DIR` | Optimised and self-hosted |
| Runtime | **Node 24 LTS** (dev machine: Node 26) | |
| Process / proxy | **PM2** + **Caddy** (auto HTTPS) on a small Linux VPS | Persistent disk for SQLite and uploads |

## Environment notes (dev machine)
- npm 11 blocks dependency install scripts by default. esbuild is approved (`npm install-scripts approve esbuild`). Review any new entry in `npm install-scripts ls` before approving it.
- Windows Application Control blocks self-compiled native addons. Prefer pure-JS packages or Node built-ins.
- `node:sqlite` transactions: run them as **synchronous** `BEGIN … COMMIT` on the raw `DatabaseSync` handle (`src/db/index.ts` exports `sqlite` and `db`). Synchronous code can't interleave with other requests, so the checkout transaction is atomic.

## Deliberately NOT used (v1)
Prisma (heavier engine), Postgres or Supabase (an external service for 60 SKUs), Auth.js / Clerk, Stripe / PayPal (high-risk merchant category), Redux, tRPC, a CMS, i18n libraries, a testing framework beyond a smoke script, Docker (optional later).

## Packages
```bash
# runtime
npm i drizzle-orm zod jose bcryptjs nodemailer zustand lucide-react react-markdown   # ✅ installed
# dev
npm i -D drizzle-kit tsx @types/nodemailer @types/node@^24                          # ✅ installed
# admin components (added when building the admin)
npx shadcn@latest init
npx shadcn@latest add button input label textarea select table card badge dialog tabs sonner dropdown-menu
```

## Scripts (package.json)
| Script | Purpose |
|---|---|
| `dev` / `build` / `start` / `lint` | standard |
| `typecheck` | `tsc --noEmit` |
| `db:generate` | `drizzle-kit generate` (SQL files in `drizzle/`) |
| `db:migrate` | `tsx scripts/migrate.ts` (applies `drizzle/` through the sqlite-proxy migrator) |
| `db:seed` | import `_capture/` (idempotent) |
| `admin:create` | create or reset an admin from the CLI |
